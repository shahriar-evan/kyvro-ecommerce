## How to run locally in VS Code:
1. Unzip `kyvro-ecommerce.zip` into a folder on your computer.
2. Open that folder in **Visual Studio Code (VS Code)**.
3. Open the integrated terminal (`Ctrl + ~` or `Cmd + ~`).
4. Run the following commands:
   ```bash
   npm install
   npm run dev
   ```
5. Open the local link shown in your terminal (usually `http://localhost:5173`) in your browser.
